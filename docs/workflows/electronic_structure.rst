Tutorial 1: Ground-State Electronic Structure Analysis
------------------------------------------------------

In this tutorial, we analyze the ground-state Kohn-Sham molecular orbitals of a :math:`\text{CsPbBr}_3` quantum dot generated by CP2K.


.. rubric:: From ``docs/part7_examples/index.rst:20-27``

Input Files Required
~~~~~~~~~~~~~~~~~~~~

* ``CsPbBr3_QD.xyz``: Cartesian geometry of the relaxed cluster.
* ``CsPbBr3_MOs.mbse``: Binary molecular orbital coefficients and eigenvalues from CP2K.
* ``BASIS_MOLOPT``: CP2K basis set library file containing ``DZVP-MOLOPT-PBE-GTH``.
* ``CsPbBr3_bulk.cif``: Bulk cubic perovskite crystallographic unit cell.


.. rubric:: From ``docs/part7_examples/index.rst:28-55``

Configuration File (``tutorial1_ground_state.yaml``)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: yaml

   system:
     mo_file: "CsPbBr3_MOs.mbse"
     xyz: "CsPbBr3_QD.xyz"
     basis_txt: "BASIS_MOLOPT"
     basis_name: "DZVP-MOLOPT-PBE-GTH"
     cif: "CsPbBr3_bulk.cif"

   fuzzy:
     run: true
     pdos_atoms: ["Pb", "Br", "Cs"]
     coop_pairs: ["Pb-Br", "Cs-Br"]
     ewin: [-4.0, 4.0]
     pdos_sigma: 0.08
     fuzzy_sigma: 0.03
     fold_to_bz: true
     g_shell: 1

   cube:
     export: true
     spacing_ang: 0.4
     nhomos: 2
     nlumos: 2


.. rubric:: From ``docs/part7_examples/index.rst:56-64``

Execution
~~~~~~~~~

Run the calculation from the terminal:

.. code-block:: bash

   qdex --config tutorial1_ground_state.yaml


.. rubric:: From ``docs/part7_examples/index.rst:65-76``

Generated Output Files
~~~~~~~~~~~~~~~~~~~~~~

* ``pdos_data_sf.csv``: Projected Density of States for Pb, Br, and Cs.
* ``ipr_data_sf.csv``: Inverse Participation Ratio (IPR) identifying orbital localization.
* ``coop_data_sf.csv``: Crystal Orbital Overlap Population for Pb–Br and Cs–Br chemical bonds.
* ``surf_core_data_sf.csv``: Core vs. surface orbital character decomposition.
* ``fuzzy_dashboard_dft.html``: Interactive HTML dashboard showing unfolded band structure overlaid on PDOS.
* ``spatial_MO_HOMO.cube``, ``spatial_MO_LUMO.cube``: 3D volumetric wavefunctions for VMD/PyMOL rendering.

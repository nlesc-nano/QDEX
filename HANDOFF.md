# Handoff: QDEX audit of QP models and excited-state frameworks

Branch `claude/gallant-wright-6u105o`, 25 September 2026. Everything below is
committed and pushed unless it is explicitly listed under "not committed".

## 1. What this work was and why

Ivan asked for a peer-review-grade audit of QDEX (formerly miniBSE), focused
on two things. The first is the quasiparticle (QP) approximations (`gw`,
`sgw-resta`, `sgw-dim`, `evgw-*`, `qsgw-*`, `sgw`, `brus`). The second is the
excited-state frameworks (BSE/TDA, kernels, SOC). The audit covered four questions:

* Are the approaches scientifically sound relative to the literature?
* Is the documentation sound, well organised and correctly formatted?
* Does the implementation match the documentation?
* Do the tests on CdSe nanocrystals pass?

Later requests, in order:

1. Add schematic figures to the docs.
2. A dielectric-environment model, `qp_gap: env`. It was built and later
   **removed at Ivan's request**: he found it not grounded in GW theory.
3. Enforce that the **same screened interaction W enters GW and the BSE**,
   rejecting incompatible combinations, and make **Z** either derived or fixed.
4. A **test set** to compare all QP × BSE combinations.
5. A comparison with the **evGW reference of Cd₁₆Se₁₃Cl₆**, the "monomer" whose
   CP2K evGW energies are the anchor stored in `MATERIAL_DB`.

Main documents:

* **`audit/AUDIT_2026-09-25_QP_EXCITED_STATES.md`:** the second-pass audit.
  - §0–6 are the original review.
  - §7 covers shared-W enforcement.
  - §8 is the evGW anchor comparison.
* **`audit/SCIENTIFIC_AUDIT.md`, `audit/POST_FIX_VERIFICATION.md`:** first-pass
  audit (pre-existing, by an earlier session or person), not modified.
* **`docs/validation/model_comparison.rst`:** QP/BSE compatibility table, Z
  guidance and how to use the comparison script.
* **`docs/validation/anchor_evgw_benchmark.rst`:** the Cd₁₆Se₁₃Cl₆ vs evGW table.

## 2. Finished (committed and pushed)

**Bug fixes**
* `--qp_gap brus`, the CLI default, crashed on every run because of argument order.
  Fixed; regression in `tests/test_cdse_integration.py` (opt-in).
* **Davidson stalled at residual ≈ tol and aborted on every large problem.** It
  used an absolute 1e-5 threshold on unnormalised correction vectors. Now it
  normalises first, uses two-pass Gram–Schmidt, a relative threshold and a
  lowest-diagonal initial guess.
  - Regression: `tests/test_davidson.py`, which fails on the old code.
  - Speed: CdSe 100×100 went from 212 s (dense) to 17 s.
* **SOC spinors used DFT energies when a QP model supplies QP energies.** As a
  result `qsgw-*` + SOC had no QP correction at all. Fixed, and the SOC gap
  printout no longer double counts the scissor.
* **SOC + `--no-exchange` crashed.** The spinor direct e–h term was gated on the
  exchange flag. Fixed (`ed3f120`).
* **Labels and citations.** The `dynamic_z` docstring and CLI help overclaimed;
  the `evgw`/`qsgw`/`sgw` help strings overclaimed; the sBSE citation had the
  wrong page (3054 → 3438).

**QP/BSE consistency (`6e50f97`)**
* Each Delta-W QP model returns the W it is built on as
  `provenance["w_bse_ev"]`, which the CLI pops before writing the JSON.
* New BSE kernel `qp` uses exactly that matrix.
  - It is the default, and the only allowed kernel, for the Delta-W models.
  - `--allow-inconsistent-kernel` reproduces legacy results.
  - `qp` is rejected for the gap-only models (`pbe`, `brus`, `gw`, a numeric
    gap), which keep an independent kernel.
  - See `resolve_bse_kernel` in `qdex/cli.py`.
* `--qp-z derived|<number>` / YAML `qp_z` is available for all Delta-W models;
  qsGW no longer hard-codes 0.80.
  - It is rejected for gap-only models (see `resolve_qp_z`).
  - Defaults are unchanged: fixed 0.8 for `sgw-*`/`sgw`, derived for
    `evgw-*`/`qsgw-*`.
* Tests: `tests/test_qp_bse_consistency.py`.

**Documentation**
* **Formatting:** 34 lists that rendered as run-on paragraphs were fixed.
  246 reader-visible migration headings and 73 stray rules were removed.
* **Tables of contents:** reordered pedagogically instead of alphabetically.
* **Corrections to match the code:** the "Penn" formula, the MNOK mixing rule,

* **Figures:** 14 SVGs in `docs/_static/figures/`, generated by

* **Build status:** `sphinx-build -W` passes. All ~4,100 rendered equations

**Test data and tools**

  - The MO files are stored as `.gz`; `.gitignore` excludes the uncompressed

## 3. Key results

**CdSe 2 nm (spin-free, 25×25, vacuum / toluene ε_out = 2.24)**

| setting | QP gap | S₁ |
|---|---|---|
| gw + Resta | 3.861 / 3.237 | 3.634 / 3.010 |
| sgw-resta, legacy mismatched kernel | 3.762 / 3.253 | 3.535 / 3.026 |
| sgw-resta, shared W, Z = 1 | 4.021 / 3.385 | 2.499 / 2.515 |
| sgw-dim, shared W, Z = 1 | 3.809 / 3.173 | 2.529 / 2.531 |

* **With SOC:** sgw-resta, shared W, Z = 1, toluene has its first bright
  state at 2.43 eV.
* **Experiment:** 2.70–2.95 eV (Yu et al. 2003 sizing curve for D ≈ 1.6–2.0 nm).
  The Aubert–Hens (Nano Lett. 2022) values were not accessible from the
  container.
* **Consistency makes S₁ solvent independent but pins its value.** With a
  consistent static W, S₁ ≈ DFT gap + bulk GW–PBE opening − bulk-screened
  binding, about 0.3 eV too low. The good agreement of the old mismatched
  runs in toluene was error cancellation.
* **Kernel dependence for `gw`:** the binding is 0.23 eV (Resta), 0.32 (DIM),
  0.27 (xs-resta), 1.38 (sBSE) and 1.68 (bare MNOK).
* **sBSE underscreens:** its monomer-only RPA gives ε_eff ≈ 1.06.
* **Active space is not converged at 25×25:** S₁ moves 2.499 → 2.475 → 2.443
  eV for 25/50/100 (sgw-resta, shared W, Z = 1).

**Cd₁₆Se₁₃Cl₆ vs evGW (vacuum, spin-free); full table in audit §8 and the docs page**
* **Reference:** evGW gap 6.029 eV; shifts from PBE −1.398 (HOMO) / +1.997
  (LUMO) eV. The supplied MO file has a DFT gap of 2.639 eV.
* **`gw`:** −0.02 eV, by construction. The residual comes from the radius:
  5.313 Å from the geometry against the stored R₀ = 5.258 Å.
* **Gap errors of the Delta-W models:**
  - `sgw-resta`: +0.19 (Z = 0.8) or +0.76 (Z = 1).
  - `sgw-dim`: −0.71 / −0.36.
  - `sgw` (sBSE): +0.15 / +0.72.
  - `qsgw-dim`: −0.22. `qsgw-resta`: +0.70.
* **The interior contrast separates Resta from DIM:** 1.01 eV against 0.11 eV,
  with the same 1.29 eV surface term.
* **The HOMO/LUMO split is about 50/50 in all Delta-W models**, against 41/59
  in evGW. The classical charging term ½qᵀΔWq cannot produce the asymmetry.

## 4. Decisions

**Made**
* **Z:** fixed 0.8 or derived was kept as the default, so old runs stay
  unchanged. Z = 1 is recommended in the docs for consistency with a static BSE.
* **Environment model removed:** `qp_gap: env` was removed at Ivan's request;
  do not reintroduce it. Its SOC energy fix was kept.
* **Anchor residual:** remains part of `gw` only.
* **Existing configs:** a Delta-W model with an explicit `kernel: resta`/`dim`
  is now an **error**. This is intentional; the migration is `kernel: qp`.
  The docs' preset YAMLs were updated.
* **Shared W representation:** atom-resolved only. `kernel: qp` requires
  `two_electron_integrals: mnok`.
* **Tolerances unchanged:** the elementwise `max(0, W_QD − W_bulk)` clipping in
  the QP ΔW and the silent `eps_out ≥ 1` clamp in qsGW were left as they are
  and documented as open.

**Open (need Ivan)**
* **Should `qp_z` default to 1.0 for the Delta-W models?** The recommendation
  is yes; it changes their numbers.
* **Radius mismatch:** fix the stored R₀ = 5.258 Å, or the radius definition,
  so that `gw` reproduces the anchor exactly.
* **HOMO/LUMO asymmetry:** whether to calibrate it, e.g. from the monomer evGW
  split, or stop reporting absolute IP/EA from the Delta-W models.
* **"Penn" ε_eff(R):** whether to replace it with a Penn-gap or Wang–Zunger
  form. It dominates the QP gap at 1.2 nm but cancels in S₁.
* **Aubert–Hens sizing:** its CdSe parameters are needed to replace Yu et al.
  as the experimental reference.
